# Biblioteca Escolar

Mariana Benavides
Evaluación Final Transversal: Desarrollo Orientado a Objetos II — Semana 9

Aplicación en Java para gestionar libros, estudiantes, préstamos y devoluciones.

## Ejecución

1. Ejecutar los tres scripts de la carpeta sql en MySQL.
2. Copiar db.properties.example como db.properties y configurar la conexión.
3. Abrir el proyecto en IntelliJ y ejecutar Main.java con Java 17 o superior.
